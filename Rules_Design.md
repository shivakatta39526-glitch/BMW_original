# Rules & Design

## 1. Visual Direction

The website must communicate: - Premium automotive luxury - BMW-inspired
precision - High performance - Modern technology - Cinematic quality -
Minimal sophistication

Avoid: - Generic SaaS dashboard appearance - Excessive rounded cards -
Bright multicolor UI - Cartoon styling - Cluttered layouts - Excessive
decorative elements

## 2. Color System

Primary visual palette: - Near-black / black backgrounds - White
typography - BMW-inspired blue for primary actions and accents - BMW M
red for performance sections - BMW i cyan for electric sections - Silver
/ grey for secondary metallic details

Existing design tokens include: - BMW blue: #1C69D4 - Dark: #0a0a0a - M
red: #E31C25 - i cyan: #00E5FF - Silver: #C0C0C0

Use accent colors purposefully rather than everywhere.

## 3. Typography

Use a clean modern sans-serif similar to: - Inter - Helvetica Neue -
Arial

Typography should use: - Large bold hero headlines - Medium-weight
navigation - Uppercase tracking for automotive labels - Strong numeric
typography for performance metrics - Light supporting text for
descriptions

## 4. Layout

Use: - Generous whitespace - Large visual sections - Strong horizontal
rhythm - Full-width cinematic imagery - Responsive max-width
containers - Clear content hierarchy

The website should feel spacious and premium.

## 5. Navigation Rules

Desktop navigation should remain minimal and fixed.

Primary links: - Models - Build Your BMW - BMW M - BMW i - Technology -
Discover - Offers

Supporting actions: - Search - Location - Account

On mobile: - Use a hamburger menu. - Display navigation in a full-screen
dark overlay. - Keep typography large and easy to tap.

## 6. Hero Rules

The hero should dominate the first screen.

Requirements: - Full viewport height - High-quality vehicle image - Dark
cinematic overlay - Strong headline - Short supporting copy - Two
primary CTAs - Subtle scroll indicator

Hero text should remain readable over imagery.

## 7. Card Rules

Vehicle cards should: - Use large vehicle photography - Have subtle
borders - Use restrained glass effects - Support hover image scaling -
Show important specifications without clutter - Provide clear Explore
and Build actions

Do not overload cards with unnecessary information.

## 8. Glass / Surface Rules

The existing visual language uses subtle glass surfaces: -
Semi-transparent dark backgrounds - Backdrop blur - Thin low-opacity
borders

Glass should support hierarchy, not become the dominant decoration.

## 9. BMW M Rules

BMW M should have a performance-focused visual identity.

Use: - Dark backgrounds - BMW M red accents - Aggressive photography -
Large performance typography - Horsepower and acceleration metrics -
Horizontal model cards where useful

## 10. BMW i Rules

BMW i should have an electric/futuristic identity.

Use: - Dark backgrounds - Cyan/electric blue accents - Clean
technology-focused typography - Range - Charging - Battery - Electric
performance

Do not make the BMW i section visually identical to the M section.

## 11. Interaction Rules

Animations should be subtle and premium: - Fade-in on scroll - Small
upward movement - Image hover zoom - Smooth modal transitions -
Configurator step transitions - Button hover transitions - Pulsing
interior hotspots

Avoid excessive animation or distracting motion.

## 12. Accessibility / Usability

Controls should: - Have clear labels - Be touch-friendly - Maintain
readable contrast - Provide visible hover/focus states - Work across
desktop, tablet and mobile

## 13. Content Rules

Keep copy concise and premium.

Use automotive language around: - Performance - Precision -
Engineering - Innovation - Driving - Luxury - Technology

Do not claim demo specifications are officially current BMW
specifications unless verified.

## 14. Responsive Rules

Desktop: - Large typography - Multi-column grids - Cinematic
compositions

Mobile: - Single-column layouts - Large touch targets - Full-screen
overlays - Horizontal scrolling only where appropriate - No horizontal
page overflow

## 15. Image Rules

Vehicle imagery should be: - High resolution - Cinematic -
Professionally composed - Consistent in visual quality

Use dark overlays where text is placed over images.

## 16. Premium Quality Rule

Every section should look intentional. Prefer fewer strong elements over
many weak decorative elements.
